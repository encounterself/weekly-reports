# 场地与污染物约束下的土壤修复选择

## R — 原文

> 土壤气相抽提利用负压驱使空气通过污染土壤空隙，夹带挥发性有机物到达地面处理；此法适用于砂质土壤。
>
> — 《867 环境学初试笔记》，第四章，extracted.txt:L1927-L1953

> 加入化学试剂或材料，使重金属形成不溶性、移动性差且毒性小的物质，降低其生物有效性。
>
> — 《867 环境学初试笔记》，第四章，extracted.txt:L2034-L2046

## I — 方法论骨架

土壤修复没有脱离场地条件的“最佳技术”。
先描述污染物的种类、形态、挥发性、溶解性、毒性和生物有效性，再描述土壤渗透性、质地、含水率、污染深度与面积。
同时识别地下水、作物、居民和生态系统等受体，以及修复扰动可能造成的二次迁移。
挥发性有机物和高渗透砂土可能支持气相抽提等路线；重金属则要围绕固定稳定、提取、转化或降低有效性选择材料和工艺。
比较时不只写去除率，还要写原位/异位、施工扰动、残余物、地下水风险、成本和长期监测。
资料中的方法用于考试条件映射，真实项目仍需现场勘查、试验和规范设计。

## A1 — 书中的应用

### 案例：砂质土壤挥发性有机物
- **问题**：挥发性有机物进入土壤后，如何在不盲目挖土的情况下降低污染？
- **方法论的使用**：资料根据砂质土壤空隙和污染物挥发性，选择负压抽提并在地面收集处理。
- **结论**：技术选择由土壤渗透性和污染物性质共同决定。
- **结果**：形成“条件—技术—收集处理”的示例流程；资料没有证明为编写者亲历。

### 案例：重金属固定稳定
- **问题**：重金属总量难以立即移除时，如何降低植物和水体暴露？
- **方法论的使用**：通过化学材料形成低溶解、低迁移和低毒性形态，降低生物有效性。
- **结论**：修复目标可以是风险和迁移性下降，而不必把“浓度归零”当作唯一标准。
- **结果**：提示必须同步关注材料适配和长期有效性；这是教材示例。

## A2 — 触发场景

### 用户会在什么情境下需要这个 skill?

1. 用户给出土壤质地、污染物类型、深度/面积和地下水条件，要求比较修复技术。
2. 题目出现砂质、黏土、挥发性有机物、重金属、生物有效性、原位/异位。
3. 用户要解释为什么某技术适用或不适用于一个具体场地。

### 语言信号（用户的话里出现这些就应激活）

- “土壤修复选型 / soil remediation / site-specific remediation”
- “气相抽提、固定稳定、电动力学、植物修复、淋洗、原位/异位”
- “酸性黏土、挥发性有机物、镉、地下水浅、作物吸收”

### 与相邻 skill 的区分

- 与 `context-capacity` 的区别：本卡把场地和污染物条件映射到修复路线；容量卡判断负荷是否超过承受能力。
- 与 `cross-media-tracing` 的区别：本卡在已知迁移风险上做技术选择；迁移卡先构建污染物路径和受体暴露图。
- 与 `preventive-material-flow` 的区别：本卡处理既有土壤污染的修复，不是生产源头减量和清洁生产。

## E — 可执行步骤

1. **建立场地与受体画像**
   - 记录土质/渗透性、含水率、污染物性质、形态、深度面积、地下水、作物和居民暴露。
   - **完成标准**：形成“污染物—土壤—受体—迁移风险”四列条件表。

2. **将条件映射到候选技术**
   - 对比原位/异位、抽提/固定/提取/生物或电动力学路线的原理、适用条件和副作用。
   - **完成标准**：至少给出一个首选方向和一个不适用方向，并逐项解释原因。
   - **判停条件**：若缺少关键土壤或地下水信息，不给唯一方案，转为调查与小试需求清单。

3. **补齐残余和验证方案**
   - 设计污染物迁移、浸出、生物有效性、作物吸收和地下水的监测，以及残余物和二次污染控制。
   - **完成标准**：修复目标可测，且长期风险不被“处理完成”掩盖。

## B — 边界

### 不要在以下情况使用此 skill

- 用户只问原位/异位或某个修复技术的名词定义。
- 用户要求真实场地的工程施工、药剂配方、剂量或安全许可。
- 题目没有污染物和土壤条件，只要求背诵修复技术列表。

### 作者在书中警告的失败模式

- 不看土壤性质和污染物特征，机械套用气相抽提或电动力学。
- 把固定稳定当成污染物消失，忽略长期浸出、生物有效性和跨介质迁移。
- 为了追求“去除”而采用会把污染转移到地下水或其他介质的方案。

### 作者的盲点 / 时代局限

- 资料为考研笔记，缺乏现场异质性、修复目标阈值、生命周期成本和长期监测数据。
- 真实项目必须依据现行土壤、地下水、农产品和危险废物规范进行调查与设计。

### 容易混淆的邻近方法论

- “原位/异位”描述土壤是否移动；“就地/迁地保护”属于生物多样性保护，两者不能混用。
