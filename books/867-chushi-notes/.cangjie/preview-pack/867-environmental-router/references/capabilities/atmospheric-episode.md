# 大气污染事件的源化学—扩散条件诊断

## R — 原文

> 风对污染物的扩散起整体输送和冲淡稀释两种作用；大气中污染物浓度与排放量成正比、与风速成反比。
>
> — 《867 环境学初试笔记》，第三章，extracted.txt:L1299-L1310

> 大气中存在二氧化氮和碳氢化合物，是形成光化学烟雾的前提；还需要充足阳光。
>
> — 《867 环境学初试笔记》，第三章，extracted.txt:L1318-L1340

## I — 方法论骨架

大气污染事件要同时看“排出了什么”和“为什么没有扩散或发生了反应”。
先区分源头直接排放的一次污染物与环境中反应生成的二次污染物。
再核对燃料、交通、工业过程等源特征，以及氮氧化物、碳氢化合物和颗粒物等前体或一次物质。
随后检查风速风向、湍流、温度层结、稳定度、逆温、地形和局地环流。
有日照和前体物时，要判断光化学反应；低温、高湿、静风和逆温时，要判断燃烧烟气的低空积聚。
控制措施应优先减少相应前体物和源强，并用气象关联监测验证，不把所有事件都当作同一种“雾霾”。

## A1 — 书中的应用

### 案例：伦敦型还原烟雾
- **问题**：燃煤城市在低温、高湿、静风和逆温天气下出现严重烟雾。
- **方法论的使用**：资料将煤炭燃烧产生的二氧化硫、一氧化碳和颗粒物与扩散受阻联系。
- **结论**：污染严重来自源特征与不利扩散条件的叠加，不是燃煤这个单一标签。
- **结果**：形成“源—气象—积聚—健康后果”的分析。该内容是教材/讲义示例，非编写者亲历。

### 案例：洛杉矶光化学烟雾
- **问题**：交通和工业排放在日照下形成臭氧、醛类等二次污染物。
- **方法论的使用**：资料把NOx、碳氢化合物、紫外线、静稳天气和盆地地形放进同一机制链。
- **结论**：治理应削减前体物并改善/利用扩散条件，而非只处理已经生成的臭氧。
- **结果**：可据此区分一次和二次污染；该案例同样是资料示例。

## A2 — 触发场景

### 用户会在什么情境下需要这个 skill?

1. 用户要判断伦敦型烟雾、洛杉矶型光化学烟雾或某次雾霾的成因。
2. 题干同时给出交通/燃煤/工业源和日照、逆温、静风、盆地等条件。
3. 用户要提出大气污染事件的前体物控制、预警和监测方案。

### 语言信号（用户的话里出现这些就应激活）

- “光化学烟雾 / 前体物 / NOx / VOCs / ozone / photochemical smog”
- “逆温、静稳、风速、湍流、盆地、城市热岛、污染积聚”
- “伦敦型和洛杉矶型烟雾有什么区别”

### 与相邻 skill 的区分

- 与 `cross-media-tracing` 的区别：本卡专门诊断大气事件的源化学和扩散条件；迁移卡处理任意污染物跨介质归趋。
- 与 `monitoring-data` 的区别：本卡确定应看哪些前体物和气象变量；监测卡负责具体布点、QA/QC和报告。
- 与 `preventive-material-flow` 的区别：本卡回答事件成因和大气控制点，不负责企业全生命周期的物料流层级。

## E — 可执行步骤

1. **识别污染源和一次/二次性质**
   - 列出燃料、交通、工业过程、颗粒物和气态前体物，标记直接排放或环境反应生成。
   - **完成标准**：能说清污染物来自哪里、哪些是前体物、哪些是二次产物。

2. **检查化学反应与扩散条件**
   - 核对日照、温度、湿度、风速风向、湍流、稳定度、逆温、地形和局地环流。
   - **完成标准**：至少指出一个源化学条件和一个积聚/扩散条件，并解释其作用。
   - **判停条件**：若题干只有污染物名称、没有气象和源信息，不断言具体事件类型，改列所需信息。

3. **配置针对性控制和监测**
   - 按事件类型削减燃烧源或NOx/VOCs等前体物，安排气象与污染物联合监测、预警和复盘。
   - **完成标准**：控制对象与成因链对应，且不是只写“加强治理”。

## B — 边界

### 不要在以下情况使用此 skill

- 用户只问PM10、PM2.5或某个气态污染物的定义。
- 用户只要求查询当前空气质量指数，不需要机制解释。
- 用户要求真实城市的排放清单、扩散模拟或控制参数，却没有数据和专业模型。

### 作者在书中警告的失败模式

- 把光化学烟雾中的臭氧当成源头直接排放物，漏掉前体物和日照反应。
- 只按排放总量判断污染，忽略逆温、静风、地形和局地环流。
- 把伦敦型和洛杉矶型污染用同一套源和气象解释。

### 作者的盲点 / 时代局限

- 原资料存在光化学烟雾化学表述可能不一致的 OCR/转录问题（extracted.txt:L1320-L1323），应以最新版教材和权威资料复核。
- 资料未提供现代化学输送模型、排放清单和实时预报参数，不能直接用于应急决策。

### 容易混淆的邻近方法论

- 大气事件诊断不是一般的污染迁移清单，也不是仅凭“天气差”做结论；必须把源化学和扩散条件同时写出。
