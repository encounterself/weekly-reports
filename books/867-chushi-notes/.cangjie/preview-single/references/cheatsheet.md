# 决策规则速查 — 867 环境学 初试高分笔记

| 能力 | 一句话规则 |
|---|---|
| 情境化环境容量与自净超载判断 | 先比较情境化输入负荷与容量/净化速率，再结合用途、污染物性质和受体后果判断是否超载。 |
| 跨介质污染物迁移路径追踪 | 沿源头—介质—迁移/转化—受体—暴露路径追踪位置、形态、毒性和生物浓缩。 |
| 富营养化外源—内源负荷诊断 | 先核算点源/非点源外源氮磷，再用证据判断底泥内源释放，按顺序配置控制措施。 |
| 大气污染事件的源化学—扩散条件诊断 | 同时核对一次/二次污染物、前体物反应、风场稳定度、逆温、地形和局地环流，再决定控源与预警。 |
| 场地与污染物约束下的土壤修复选择 | 先匹配土壤渗透性、污染物性质、深度面积和受体风险，再选择降低暴露/迁移的修复路线。 |
| 预防生产与物料流层级 | 按输入减量→过程改造→产品/再利用/再循环→不可避免残余末端处理的顺序设计方案。 |
| 预测—对症—轮换的农药风险控制 | 先预测确认虫情，再按对象选药和剂量、轮换机制并保护天敌与受体，最后核对安全间隔和残留。 |
| 受纳能力约束的农业资源闭环 | 先核对农田受纳容量、季节、距离、储存和成本，再让粪污或副产物安全进入真实闭环。 |
| 目的驱动的监测与有效数据闭环 | 从问题目的反推调查、点位、时频和方法，经QA/QC与有效性核验后再评价、报告并反馈治理。 |
| 多目标环境规划的备选方案决策 | 先按功能和现状定目标、算削减量，再比较多方案的技术、经济、生态风险和实施保障。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
