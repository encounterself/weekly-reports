## I — 方法论骨架

监测不是把仪器读数堆在一起，而是为一个明确的决策问题设计证据链。
先说清楚要回答环境现状、污染源排放、变化趋势还是应急范围，再调查污染源、受体、相对位置和水文/气象条件。
据此确定监测因子、范围、点位、时间、频次、人员、运输和实验室分工。
采样和分析必须按方法和规范执行，同时以空白、校准、平行样、加标样等检查数据质量。
评价时保留有理由的异常值，正确处理检出限以下结果，不把超出方法灵敏度的数据直接上报。
最后按标准解释和报告；若结果不符合预期或质量要求，应补测/重测，并把结论反馈到治理与下一轮监测。

## A1 — 书中的应用

### 案例：环境污染趋势与污染源监测
- **问题**：如何长期掌握环境质量变化并监督污染源排放？
- **方法论的使用**：资料区分常规、研究和应急监测，并要求按目的布点、采样、分析和评价。
- **结论**：同一环境对象因监测目的不同，设计不能照搬。
- **结果**：形成从问题到报告的监测流程。该内容是教材/讲义示例，资料没有证明为编写者亲历。

### 案例：质量控制和有效数据报告
- **问题**：测量出现低于检出限的值或异常极值，能否直接删除或填报？
- **方法论的使用**：资料要求内部/外部质量控制，说明检出限处理和极值保留原则。
- **结论**：数据先经过有效性、完整性和可解释性核验，再进入环境评价和管理。
- **结果**：避免为了结果好看而修改数据；这是来源示例而非个人实验记录。

## A2 — 触发场景

### 用户会在什么情境下需要这个 skill?

1. 用户要设计常规、研究或应急环境监测计划，且采样机会或预算有限。
2. 题目出现监测目的、布点、时频、空白、平行样、加标样、检出限、极值或上报。
3. 用户要把监测结果用于富营养化、污染源监督、农产品安全或环评跟踪。

### 语言信号（用户的话里出现这些就应激活）

- “环境监测方案 / sampling plan / monitoring design / 应急监测”
- “QA/QC、质量保证、质量控制、空白、校准、平行样、加标样”
- “检出限、未检出、极值、有效数据、能否上报”

### 与相邻 skill 的区分

- 与 `cross-media-tracing` 的区别：迁移卡先决定路径和受体；本卡将目标和路径转成点位、时频、方法及数据质量流程。
- 与 `eutrophication-load` 的区别：富营养化卡诊断外源/内源氮磷；本卡适用于任何监测目的并规定如何验证证据。
- 与 `planning-alternatives` 的区别：本卡产出有效监测数据；规划卡用现状、预测和数据比较多方案。

## E — 可执行步骤

1. **确定监测目的和决策问题**
   - 明确是现状、趋势、排放监督、研究还是应急，列出需要支持的判断。
   - **完成标准**：能说明结果将影响哪个治理或评价决定。

2. **调查并制定采样计划**
   - 调查源、受体、相对位置、水文、地理、气象和历史情况，确定因子、范围、点位、时间、频次和分工。
   - **完成标准**：计划中的每个点位和时间都有目的依据。
   - **判停条件**：若源/受体/流向等关键条件不明，不假装给出最优点位，先列现场调查项。

3. **实施、质控、评价与反馈**
   - 按规范采样分析，执行空白、校准、平行、加标和外部样品等QC；处理检出限、极值和无效数据后再评价、报告。
   - **完成标准**：输出数据有效性结论、环境评价、异常说明和下一步治理/补测行动。
   - **判停条件**：结果不符合预期或质量要求时，补充或重新检测，不靠删除异常值修正结论。

## B — 边界

### 不要在以下情况使用此 skill

- 用户只想知道一个监测术语定义，不需要设计或数据审查。
- 用户要求当前标准中的具体采样保存、方法检出限或实验室认可判断，却没有指定规范版本。
- 用户要以少量未经质控的数字直接做法律、健康或工程安全结论。

### 作者在书中警告的失败模式

- 不先明确目的就照搬监测设计，导致点位和时频无决策价值。
- 把所有读数当成有效数据，随意删除极值或上报超出方法灵敏度的结果。
- 没有空白、校准、平行和加标等质量控制，却直接进行综合评价。

### 作者的盲点 / 时代局限

- 资料为考试流程，未给出最新监测方法标准、统计功效、实验室认可和不确定性量化要求。
- 未检出值处理、阈值和上报规则必须按当前方法和监管规范复核，不能机械套用笔记表述。

### 容易混淆的邻近方法论

- 监测是获取和验证证据，环境质量评价是按标准解释状态，环评和规划是据此预测与决策；四者输出不同。
