# 867 环境学考试复习工作区

这是考试分析层与 `study-assistant-skills` 的连接工作区，不重新蒸馏教材。

- `open/dashboard.html`：当前学习仪表盘；
- `internal/state/knowledge.json`：按考试权重排序的 10 个课程节点；
- `internal/state/exam-style.md`：真题题型和答题风格；
- `question-bank/question-bank.json`：134 条已确认真题记录；
- `../真题/analysis/`：完整证据、趋势和知识点—题目索引。

推荐顺序：先打开 `../真题/analysis/priority-summary.md`，再在本工作区按 `knowledge.json` 的节点逐个学习；每完成一个节点，再使用 `study-quiz`、`study-feynman` 和错题流程进行检验。
